# 15 · 双端原生：一键交付

> 目标：拿到 **项目链接** + **Android 原生录屏** + **iOS 原生录屏**，发到 `ltx@techlz.com`。
> 本机不需要 Android SDK、Xcode、Mac。编译和录屏都在 GitHub Actions 上完成。

## 0. 先做一次安全清理

如果 GitHub token 曾经出现在聊天、截图、录屏里：

1. 打开 GitHub → Settings → Developer settings → Personal access tokens
2. 找到旧 token，点 **Revoke**
3. 新建一个 **classic token**，只勾：
   - `repo`
   - `workflow`
4. 把新 token 保存到 `secrets/token.txt`，**不要发到聊天里**

`secrets/` 已在 `.gitignore` 里，不会被提交。

## 1. 一键出片

双击根目录的 `一键交付.bat`。

> 建议顺序：先做第 2 节部署 Cloudflare，再回来双击本文件。这样 Android APK 一次就是连公网的。  
> 如果先跑本节也没关系，之后部署完 Cloudflare 再跑一次即可。

它会自动：

| 步骤 | 结果 |
|---|---|
| 建公开仓库、推代码 | `https://github.com/<你的用户名>/moneynote` |
| 触发 `native-ios-build.yml` | SwiftUI 在 macOS 模拟器里自动演示并录 45 秒 |
| 触发 `native-android-build.yml` | Kotlin/Compose 在 Android 模拟器里自动演示并录 45 秒 |
| 下载产物 | `dist\demo-ios.mp4`、`dist\demo-android.mp4`、APK、截图 |

演示流程是固定的：**首页 → 记一笔 → 保存 → 统计 → 切月份**。  
演示模式只在 CI 构建时开启：Android 用 `-PdemoMode=true`，iOS 用启动参数 `--demo`。正常安装包不会自动操作。

第一次跑如果红叉，打开 Actions 日志里第一个打红叉的步骤，整段复制给 AI；不要自己猜。

## 2. 部署云端后端（Cloudflare Workers + D1）

线上后端用 **Cloudflare Workers + D1**。它按请求运行，不存在 Render 那种“15 分钟没人访问就休眠”；你的电脑关机也不影响。

1. 双击根目录的 **`一键部署Cloudflare.bat`**。
2. 不需要先注册 Cloudflare。脚本会自动创建一个 **60 分钟临时预览账号**，并弹出领取页。
3. 脚本自动完成：
   - 创建 D1 数据库 `moneynote-d1`
   - 建表
   - 空库时灌入和录屏同一批演示数据
   - `wrangler deploy`
   - 把 Worker 地址写进 `dist\cloudflare-url.txt`
4. 脚本最后会显示并检查：  
   `https://moneynote-api.<你的子域>.workers.dev/api/health`  
   看到 `{"ok":true}` 就成功。
5. **在 60 分钟内领取**：浏览器里登录或注册 Cloudflare，点 **Claim / 领取**。领取后 Worker 和 D1 永久保留，地址不变。

> 领取链接也会写到 `dist\cloudflare-claim.txt`；这个链接等同于账号凭证，不要发到公开群。  
> 已经登录 Cloudflare 的话，脚本会直接用永久账号，不再创建临时账号。  
> 想用 API Token：先 `set CLOUDFLARE_API_TOKEN=...`，再运行同一个 bat。token 至少需要 Workers Scripts:Edit 和 D1:Edit。

线上后端的代码在 `worker/`；`backend/` 仍然保留，用于本地和 GitHub Actions 录屏。两边接口协议一致，Android/iOS 不需要改代码。

D1 是持久化数据库，重启不会清空。部署脚本只在空库时灌演示数据，不会覆盖你后来记的账。

## 3. 让 Android APK 连公网

不需要手动设地址。`一键部署Cloudflare.bat` 成功后，直接再双击：

```bat
一键交付.bat
```

`一键交付.bat` 会自动读取 `dist\cloudflare-url.txt`，把地址传给 `native-android-build.yml`。这次编译出的正常版 APK 连的是 Cloudflare，下载到 `dist\moneynote-native.apk`；Actions 的 `native-android-apk` artifact 里也有一份。

装到 Android 手机上后，**这台电脑关机、手机用流量/别的 Wi-Fi，仍然能记一笔、看统计**。

如果 `dist\cloudflare-url.txt` 不存在，也可以手动指定：

```bat
set API_BASE_URL=https://moneynote-api.<你的子域>.workers.dev
一键交付.bat
```

iOS 真机安装需要 Apple 开发者签名；当前交付的 iOS 证据是 **Xcode 模拟器录屏**，不是真机安装包。这一点邮件里要如实写。

## 5. 常见问题

**Q：iOS 工作流在 `xcodegen generate` 失败？**  
看 `native/ios/project.yml` 是否被改坏；本地不需要装 XcodeGen，CI 会 `brew install xcodegen`。

**Q：Android 工作流在 Gradle 下载依赖时失败？**  
多半是网络抖动，重新跑一次；连续失败再看 `native/android/app/build.gradle.kts` 的版本号。

**Q：录屏里 App 显示「连不上后端」？**  
CI 里后端没起来。看 workflow 的「启动本机后端」步骤和最后的「后端日志」。

**Q：iOS 能装到真 iPhone 吗？**  
代码是原生 SwiftUI，可以用 Xcode 打开 `native/ios` 生成工程后签名安装；但需要 Apple 账号/证书，不属于零基础一键流程。  
真机要连 Cloudflare 时，把 `native/ios/MoneyNote/Api.swift` 里的 `example` 换成你的 Worker 子域，或启动时设置 `API_BASE_URL`。

**Q：Cloudflare 部署失败怎么排查？**  
先看 `一键部署Cloudflare.bat` 最后一段报错：
- 临时账号超过 60 分钟没领取：重跑，会重新开一个，然后马上领取。
- `D1` 创建失败：到 Cloudflare 控制台左侧 **Workers & Pages** 确认账号已启用 D1。
- 网络/代理拦截 `api.cloudflare.com`：关代理或换网络。
- 已经部署过、只想更新代码：重跑同一个 bat；数据库不会重置。
- 健康检查显示“没通”不代表部署失败：国内网络可能拦截 `workers.dev`，换手机网络或等 DNS 生效；领取后地址不变。

**Q：为什么不用 Render 了？**  
Render 免费实例 15 分钟没访问会休眠，首次唤醒要 30~60 秒；Cloudflare Workers 按请求运行，不存在这个问题。`render.yaml` 仅作为备用配置保留。

**Q：Flutter 版还要吗？**  
`app/` 保留作跨平台备份。投递主项目是 `native/android` + `native/ios`，邮件里不要写 Flutter。
