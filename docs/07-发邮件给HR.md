## 六、简历上怎么写

只有一行位置：

> **MoneyNote · Android + iOS 双端原生记账 App**（个人项目）
> Kotlin/Compose + SwiftUI + Cloudflare Workers/D1；自研 REST 后端；云端 CI 自动构建与模拟器录屏。
> github.com/zhangsan/moneynote

有三到五行的位置，加上：

- Android 端用 Kotlin + Jetpack Compose，iOS 端用 SwiftUI，两套独立原生客户端共用 REST API
- 线上后端 Cloudflare Workers + D1；本地 / CI 用 Node.js + Express，SQL 收敛在 repo 层；金额以整数分存储
- GitHub Actions 的 macOS / Ubuntu runner 完成双端编译、模拟器自动演示和 45 秒录屏

**不要写**：

- ❌「精通 Kotlin / Swift」——一个个人项目撑不起「精通」
- ❌「双端原生」却拿 Flutter 代码交差——会被追问
- ❌ 罗列没用到的技术名词
