# 07 · 发邮件

**这是整个项目的终点。前面所有事都是为了让这封邮件有东西可写。**

---

## 一、先看清楚对方要什么

招聘信息里这几句是硬要求：

> 可发项目链接和**应用功能录屏**到邮箱 `ltx@techlz.com`
> （记得备注**姓名**，最好附上**简历和联系方式**！！！）

拆开就是五样东西，少一样都扣分：

| 要的 | 你有什么 |
|---|---|
| 项目链接 | GitHub 仓库地址 |
| 应用功能录屏 | `demo-android.mp4`（+ iOS 录屏） |
| 姓名 | 邮件里写清楚 |
| 简历 | 一份 PDF 附件 |
| 联系方式 | 手机 + 微信 + 邮箱 |

**四个感叹号不是装饰。** 对方大概被很多"发个压缩包过来也不说谁是谁"的邮件烦过。你把这五样一次给齐，就已经赢过一半投递者了。

---

## 二、邮件主题

主题决定对方**会不会点开**。格式：

```
Android/iOS 双端原生 Demo 投递 - 张三 - 13800138000
```

要点：

- 岗位关键词放最前面（让对方一眼知道是投什么的）
- **姓名和手机号直接写在主题里**，省得对方翻正文
- 不要写「应聘」「求职」这种没信息量的开头
- 不要全角符号混排，不要 emoji

>
> 项目链接：https://github.com/zhangsan/moneynote

> 安卓安装包：https://pan.baidu.com/s/yyyy　提取码：yyyy
> iOS 构建日志：见邮件末尾截图
>
> **技术栈**
> - 客户端：Flutter 3.x（AOT 编译为各平台原生二进制，非 WebView 套壳）、Dart 3
> - 状态管理：ChangeNotifier + InheritedNotifier（未引入第三方状态管理库）
> - 后端：Node.js 24 + Express 5，接口遵循 REST，统一错误码
> - 数据存储：SQLite（Node 内置 `node:sqlite`，零原生依赖）
> - 工程：GitHub Actions 做 iOS 云端构建，75 条断言的后端冒烟测试 + 单元测试
>
> **三个我着重处理的地方**
> 1. **金额用整数「分」存储**。浮点数存钱会累积误差（`0.1 + 0.2 ≠ 0.3`），账目会对不上。所以在数据库层存分，只在 API 出入口做一次换算，并写了测试锁住这个行为。
> 2. **日期用 `YYYY-MM-DD` 字符串而非 DateTime 对象**，彻底避开「本地时区 vs UTC 差一天」这类问题，字符串比较即日期比较。
> 3. **离线优先**。打开 App 先渲染本地缓存再请求网络；网络失败不清空界面，只挂提示条。录屏最后 10 秒演示了「停掉后端下拉刷新，数据依然可见」。
>
> **过程中我自己抓出来并修复的一个 bug**
> 月份切换函数原本写成 `year += (mon - 1) ~/ 12`。Dart 的 `~/` 是**向零截断**而非向下取整，`(-1) ~/ 12 == 0`，导致「1 月往前推一个月」算成同年 12 月。写单元测试时才暴露，已改为「换算成总月数再换算回来」，并补了跨年、跨多年的测试用例。
>

## 四、附件怎么起名

**别用** `简历.pdf`、`录屏.mp4`、`新建文件夹.zip`。

**要这样**：

```
张三_简历_Flutter移动开发.pdf
张三_MoneyNote演示录屏_Android.mp4
张三_MoneyNote演示录屏_iOS模拟器.mp4
```

理由：对方下载完一周后，**从文件名就能想起你是谁、投的什么**。这个细节几乎没人做，做了会被记住。

## 五、发送前的检查清单

一条条对，别跳。

**内容**
- [ ] 主题里有**岗位关键词 + 姓名 + 手机号**
- [ ] 正文里有姓名、手机、微信、邮箱
- [ ] GitHub 链接**点开是公开仓库**（用浏览器无痕模式验证一遍！）
- [ ] README 在仓库首页能直接看到（我写的 README 已经是这个用途）
- [ ] 录屏链接**没有过期**（网盘链接设成永久有效）
- [ ] 简历是 PDF，不是 Word（Word 在不同电脑上会排版错乱）

**技术**
- [ ] `flutter analyze` 无 error
- [ ] `flutter test` 全过
- [ ] `npm run smoke` 全过
- [ ] 录屏前完整走过一遍：冷启动 → 记一笔 → 编辑 → 删除 → 看统计
- [ ] release 版 APK 真机装过、能拉到数据（**调试版能跑不代表 release 能跑**）

**邮件本身**
- [ ] 附件总大小 < 20MB（超了就把视频压到 720p）
- [ ] 抄送一份给自己，确认收到后附件能正常打开
- [ ] 正文里没有「贵公司」写成「跪公司」这类错别字
- [ ] **发之前自己通读一遍**

## 六、简历上怎么写这个项目

只有一行位置的话：

> **MoneyNote · 双端原生记账 App**（个人项目，Flutter + Node.js）
> 一套代码编译至 Android/iOS 双端；自研 REST 后端，SQLite 存储。
> 处理了金额浮点精度、时区、离线缓存等工程问题；含 75 条后端断言测试。
> github.com/zhangsan/moneynote

有三到五行的位置，加上：

- 客户端用 Flutter，AOT 编译为各平台原生二进制；状态管理未引三方库，用框架自带的 `ChangeNotifier` + `InheritedNotifier`
- 后端 Node.js + Express，分层为 route / repo / db 三层，所有 SQL 收敛在 repo 层
- 用 GitHub Actions 的 macOS runner 完成 iOS 端持续构建与模拟器录屏

**不要写**：
- ❌「熟练使用 AI 辅助开发」——这是工具，不是技能
- ❌「精通 Flutter」——一个个人项目撑不起"精通"，面试官会专门挑刺
- ❌ 罗列一堆没用到的技术名词

## 七、发完之后

**别干等。** 做这三件事：

1. **把项目的 8 个高频问题背熟**（[08](08-面试准备.md)），对方大概率一两天内就会联系你
2. **继续改代码**（[04 第五节](04-用AI写代码.md)的练习清单）。万一对方问"你最近在做什么"，你有东西说
3. **同时投别家**。这封招聘只是其中一个机会
