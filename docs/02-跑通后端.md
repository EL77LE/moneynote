# 02 · 跑通后端

目标：浏览器里能看到接口返回 JSON。

后端代码已经写好了，**不需要你写一行**。这一步只是验证它能跑。

**预计耗时：10 分钟。**

---

## 1. 三条命令

```bash
cd C:\Users\chenj\eclipse-workspace\demo0\backend

npm install     # 约 5 秒，67 个包
npm run seed    # 生成几十条演示数据（每次随机）
npm run dev     # 启动
```

看到这个就成了：

```
  MoneyNote API 已启动
  数据库文件   C:\Users\chenj\eclipse-workspace\demo0\backend\data\moneynote.db
  本机访问     http://localhost:3000
  安卓模拟器   http://10.0.2.2:3000
  局域网真机   http://192.168.x.x:3000
```

**这个终端窗口别关。** 后端得一直跑着，App 才有数据。

## 2. 验证一下

浏览器打开 <http://localhost:3000>，应该看到接口清单。

再打开这几个：

- <http://localhost:3000/api/health> → `{"ok":true,...}`
- <http://localhost:3000/api/records?month=2026-10> → 一长串记录
- <http://localhost:3000/api/stats?month=2026-10> → 总额 + 分类 + 每日趋势

> 把 URL 里的 `2026-10` 换成当前月份。`seed` 脚本是按"今天"生成数据的。

## 3. 跑测试（可选，但强烈建议看一眼）

**另开一个终端**（后端那个别关）：

```bash
cd C:\Users\chenj\eclipse-workspace\demo0\backend
npm run smoke
```

应该看到：

```
  全部通过：75 项断言
```

这个脚本会自己拉起一个临时服务、打 77 条断言、跑完自动关掉，**不会碰你 `data/` 里的数据**。

它测了什么值得你知道（面谈可能被问）：

- 月份边界：2024 年 2 月是 29 天，2026 年 2 月是 28 天
- 8 种非法输入全部被拦：金额为 0、负数、字符串、类型乱填、分类为空、日期格式错、`2026-02-30` 这种不存在的日期、备注超长
- `0.1 + 0.2` 加起来必须是 `0.3`，不能是 `0.30000000000000004`
- 删掉的记录再查要返回 404，重复删除也返回 404
- 服务进程跑完全程没有崩

## 4. 前端要连的地址

后端启动日志打印了三行地址，对应三种情况：

| 你在哪跑 App | 用哪个地址 | 为什么 |
|---|---|---|
| Android 模拟器 | `http://10.0.2.2:3000` | 模拟器里的 `localhost` 指模拟器**自己**，`10.0.2.2` 才是宿主机 |
| iOS 模拟器 | `http://localhost:3000` | iOS 模拟器跟 macOS 共享网络栈，`localhost` 就是对的 |
| 真机（安卓/iPhone 都是） | `http://192.168.x.x:3000` | 用日志里打印的那个局域网 IP，手机和电脑必须在**同一个 WiFi** |

**这三种情况 App 会自己判断，你不用改代码。** 逻辑在 `app/lib/core/app_config.dart`。

真机调试时可以手动覆盖：

```bash
flutter run --dart-define=API_BASE_URL=http://192.168.1.7:3000
```

## 常见问题

| 现象 | 怎么办 |
|---|---|
| `EADDRINUSE` 端口被占 | 上一次的服务没关干净。`PORT=3001 npm run dev` 换个端口，或者重启终端 |
| `npm install` 报错 | 确认 Node 版本 ≥ 22.13（`node -v`）。本项目**没有原生依赖**，正常不会编译失败 |
| 浏览器中文变乱码 | 那是浏览器编码问题，不影响。JSON 是 UTF-8 的 |
| 数据想重置 | 删掉 `backend/data/` 文件夹，再 `npm run seed` |
