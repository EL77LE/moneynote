## 第 1 节：注册 GitHub（已经有账号就跳到第 2 节）

GitHub 是免费代码托管网站，也是我们借它「免费云端电脑」的地方。

1. 打开 <https://github.com>
2. 点右上角 **Sign up**
3. 填邮箱、密码、用户名（用户名会出现在你的项目链接里，用英文/数字，例如 `zhangsan-dev`）
4. 去邮箱收验证码，填回去
5. 注册完成后，**记住你的用户名**（不是邮箱，是 `github.com/` 后面那一串）

> 不需要绑卡，不需要付费。免费账号就能建公开仓库、跑 GitHub Actions。

## 第 2 节：获取 GitHub 令牌（2 分钟，只需要做一次）

### 2.1 令牌是什么

令牌（token）是一串以 `ghp_` 开头的字符，相当于「给这个脚本的一次性钥匙」。
脚本靠它帮你**建仓库、推代码、触发云端构建**。

GitHub 规定：任何程序都不能自己给自己发钥匙。所以这一步必须你本人点一次。

### 2.2 最省事的做法

**直接双击项目根目录的 `一键交付.bat`。**
脚本会自动打开令牌创建页面，权限也帮你勾好了，你只要：

1. 页面往下拉，确认 `repo` 和 `workflow` 两个**是勾上的**
2. 点最下面的绿色按钮 **Generate token**
3. 页面顶部出现一串 `ghp_...`，点它旁边的**复制按钮**
4. 回到黑色窗口，粘贴，按回车

> ⚠️ 这串字符**只显示这一次**。刷新页面就再也看不到了。
> 没复制成功就重新跑一次脚本，它会再给你打开一次。

### 2.3 手动创建（脚本没打开页面时）

1. 登录 GitHub
2. 打开这个地址（权限已经预选好）：

   <https://github.com/settings/tokens/new?scopes=repo,workflow&description=MoneyNote-oneclick>

3. **Note** 填 `MoneyNote-oneclick`（随便写）
4. **Expiration** 选 `30 days` 或 `90 days` 都行
5. 往下拉，勾选：
   - `repo` —— 建仓库、推代码
   - `workflow` —— 触发云端构建
6. 点 **Generate token**
7. 复制顶部那串 `ghp_...`（用旁边的复制按钮，不要手动选中网页文字）

### 2.4 粘贴时的常见错误

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 提示「里面有非 ASCII 字符」 | 你把网页上的中文说明一起复制了 | 只点令牌旁边的复制按钮 |
| 提示「只有 xx 个字符，太短」 | 只复制了一半 | 重新复制完整的一串 |
| 提示「不是 GitHub 令牌的样子」 | 复制成了密码或其他东西 | 重新生成一个 |
| 提示 401 | 令牌过期、被撤销、或复制错 | 删掉 `secrets\token.txt`，重跑脚本 |

令牌会被存到 `secrets/token.txt`。这个目录已经写进 `.gitignore`，**不会被提交到 GitHub**。
但它在本机是明文，所以：别发别人、别拷网盘。怀疑泄露就去 GitHub 设置里撤销重发。

## 第 3 节：拿到测试用的短视频（最核心的一步）

### 3.1 全自动：双击一个文件

1. 打开项目根目录 `C:\Users\chenj\eclipse-workspace\demo0`
2. 双击 **`一键交付.bat`**
3. 第一次会让你粘令牌（第 2 节），之后不用再粘

它会自动做这些事：

```

**首页 → 记一笔（25.5 元 / 餐饮 / 午饭）→ 保存 → 统计 → 切上个月 → 回本月**。

跑完后你会得到：

├── demo-android.mp4         ← 安卓模拟器录屏
├── demo-ios-截图.png
└── demo-android-截图.png
```

以及一行项目链接：

```

```

> **这就是招聘要的「项目链接 + 应用功能录屏」。**
> 两段视频加起来通常十几 MB，邮件附件一般放得下；放不下就传网盘，把链接写进邮件。

### 3.2 如果脚本失败了：去 GitHub 手动下载

脚本失败时会把一个运行页面链接打印出来。你也可以自己找：

1. 打开 `https://github.com/<你的用户名>/moneynote/actions`
2. 左边选「iOS 模拟器构建与录屏」或「安卓构建与录屏」
3. 点最新的一次运行
4. 往下滚到底部，找到 **Artifacts**
5. 下载：
   - `ios-simulator-recording`
   - `android-emulator-recording`
6. 解压 zip，里面就是 `.mp4`

如果运行页面上是红叉：点开红叉那一步，把日志整段复制给 AI，问「这是 GitHub Actions 的报错，帮我看看」。

### 3.3 自动录屏够不够？

够。它已经不是「只录首页」了：CI 构建的是带演示模式的安装包，
App 启动后会自动完成一次真实记账，再切到统计页、切换月份。
每一步都走真实的接口请求，不是假动画。

如果 HR 还想要更长的真人操作视频，**用手机自己录** 60~90 秒，这是加分项：

#### 安卓手机

1. 从屏幕顶部下拉，找到「屏幕录制」（没有的话在快捷设置里编辑添加）
2. 开始录制
3. 打开 App，按下面的脚本操作
4. 停止录制，视频在相册里

#### iPhone

1. 设置 → 控制中心 → 把「屏幕录制」加进去
2. 从右上角下拉控制中心，点圆点图标，3 秒后开始
3. 打开 App，按脚本操作
4. 点顶部红色状态栏 / 灵动岛停止，视频在「照片」里

#### 录屏脚本（照着做，60~90 秒）

1. **首页**：让镜头停 3 秒，能看到本月支出、收入、结余和明细
2. 点右下角「记一笔」
3. 金额输入 `25.5`，选「餐饮」，备注随便写「午饭」
4. 点保存，回到首页，让新记录出现在列表里
5. 点底部「统计」，展示分类占比和趋势
6. 切一下月份，展示数据会变
7. 停止录制

> 录屏时关掉微信/短信弹窗，别露出真实姓名、手机号、余额。
> 用演示数据就行，这个项目启动时会自动生成几十条假数据（每次随机）。

## 第 4 节：把后端部署到云端（Render，免费，不用服务器）

> 后端部署是**加分项**，不是拿到录屏的前提。
> 但部署之后，App 不连你电脑也能用，面试官点开网页版也能直接看到数据。

### 4.1 注册 Render

1. 打开 <https://render.com>
2. 点 **Get Started** / **Sign in**
3. 选 **GitHub** 登录（不用另外注册账号）
4. 授权 Render 读取你的仓库

> 免费实例不需要付费。Render 可能要求邮箱验证或身份验证，
> **以页面提示为准**；如果要求绑卡，先确认你选的是 Free 实例，别选付费套餐。

### 4.2 用 Blueprint 一键部署（推荐）

仓库根目录已经有 `render.yaml`，里面写好了构建命令、启动命令、免费实例、新加坡区域、自动补演示数据。

1. Render 控制台点 **New +** → **Blueprint**
2. 如果看不到你的仓库，点 **Configure account**，把 `moneynote` 这个仓库授权给 Render
3. 选中 `moneynote` → 点 **Apply**
4. 等 3~5 分钟，状态变成 **Live**
5. 页面顶部会给你一个地址，形如：

   ```
   https://moneynote-api.onrender.com
   ```

6. 在手机或电脑浏览器打开：

   ```
   https://moneynote-api.onrender.com/api/health
   ```

   看到 `{"ok":true,...}` 就成功了。

### 4.3 Blueprint 看不到仓库 / 部署失败：手动建一个

1. **New +** → **Web Service**
2. 连接你的 `moneynote` 仓库
3. 按下面填：

| 字段 | 填什么 |
|---|---|
| Name | `moneynote-api` |
| Region | `Singapore` |
| Branch | `main` |
| Root Directory | `backend` |
| Runtime | `Node` |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type | `Free` |
| Health Check Path | `/api/health` |

4. 在 **Environment Variables** 里加两条：

| Key | Value |
|---|---|
| `NODE_VERSION` | `24` |
| `AUTO_SEED` | `1` |

5. 点 **Create Web Service**，等它变 Live。

> `AUTO_SEED=1` 的作用：免费实例重启后数据库会清空，
> 这个开关会在**空库**时自动补几十条演示数据，面试官打开不会看到空账本。
> 它只在空库时动手，不会清掉已有数据。

### 4.4 免费实例的两个正常现象

| 现象 | 是不是坏了 | 怎么办 |
|---|---|---|
| 15 分钟没人访问后，第一次打开要等 30~60 秒 | 不是，免费实例会休眠 | 等它醒；录屏前先打开一次 `/api/health` 唤醒 |
| 重新部署后数据变回几十条演示数据 | 不是，免费磁盘是临时的 | 演示够用；`AUTO_SEED` 会自动补 |

### 4.5 电脑关机以后，哪些东西还能访问？

这是「部署到云端」最关键的一张表：

| 东西 | 电脑关机后 | 说明 |
|---|---|---|
| GitHub 项目链接 | ✅ 能 | 代码在 GitHub 上，和你电脑无关 |
| GitHub Pages 网页版 | ✅ 能 | 静态页面由 GitHub 托管 |
| Render 后端 API | ✅ 能 | 免费实例会休眠，第一次打开等 30~60 秒 |
| 已经装到安卓手机里的 APK | ✅ 能 | App 在手机上跑，只向后端发请求 |
| iOS 模拟器录屏 | ✅ 能 | 已经是一个 `.mp4` 文件 |
| iOS 真机安装包 | ⚠️ 不行 | 需要 Apple 开发者签名 + macOS，超出零基础范围 |
| 第 6 节的 Cloudflare 隧道 | ❌ 不能 | 隧道从你电脑出去，电脑必须开着 |

所以「电脑关机也能用」的正确组合是：

```
GitHub 仓库（代码）
  + GitHub Pages（网页）
  + Render（后端 API）
  + 安卓 APK（装在手机上）
```

四个都在云端或手机上，你的 Windows 电脑可以关。

> ⚠️ Render 免费档的 SQLite 是临时磁盘：重新部署/重启会清空，
> 然后 `AUTO_SEED` 自动补演示数据。给 HR 演示够用；
> 要长期保存真实账目，得换付费磁盘或外部数据库，那已经超出这次投递的范围。

## 第 5 节：让 App 和网页连上云端后端

部署完只拿到一个后端地址还不够，前端要知道这个地址。

### 5.1 安卓 APK 连云端

在项目根目录打开一个命令行窗口（在文件夹地址栏输入 `cmd` 回车），执行：

```bat
set API_BASE_URL=https://moneynote-api.onrender.com
一键交付.bat
```

脚本会把地址传给安卓工作流，编出来的 APK 就能直接装到真机上、连公网后端。
产物在：

- 本机：`dist\` 里的录屏
- GitHub：Actions → 安卓构建与录屏 → 最新运行 → Artifacts → `android-apk`

> 不设 `API_BASE_URL` 时，安卓走「模拟器模式」，APK 只能连模拟器里的宿主机，
> 装到真机上会显示连不上。这是正常的，不是 bug。

### 5.2 网页版连云端

1. 打开仓库 **Settings** → **Secrets and variables** → **Actions**
2. 选 **Variables** 标签（不是 Secrets）
3. 点 **New repository variable**
4. Name 填 `API_BASE_URL`
5. Value 填你的后端地址，**必须是 `https://` 开头，末尾不要加 `/`**
6. 保存

然后：

1. 仓库 **Settings** → **Pages**
2. **Source** 选 **GitHub Actions**
3. 打开 **Actions** → 左边选「部署 Web 版到 GitHub Pages」→ **Run workflow**
4. 等它跑完，站点地址是：

   ```
   https://<你的用户名>.github.io/moneynote/
   ```

> 第一次部署如果 404，等 1~2 分钟再刷新。
> 页面白屏、控制台报 `localhost:3000`，说明 `API_BASE_URL` 没设或没生效，回去检查第 5.2 节。

### 5.3 iOS 录屏连的是哪个后端？

自动 iOS 录屏用的是**同一次运行里启动的本机后端**（`http://localhost:3000`），
这样最快、最稳，不需要等 Render 睡醒。

如果你要一个连公网后端的 iOS 安装包，需要 macOS + Xcode 手动编译：

```bash
flutter build ios --release --dart-define=API_BASE_URL=https://moneynote-api.onrender.com
```

这一步超出「零基础」范围，**不影响你交录屏和项目链接**。

## 第 6 节：连 Render 都不想注册？用自己电脑 + 免费隧道

如果你只是想临时给面试官看一个公网地址，不想注册 Render：

1. 先在本机把后端跑起来：

   ```bat
   cd backend
   npm install
   npm run seed
   npm start
   ```

   停在这个窗口，不要关。

2. 再开一个命令行窗口，下载 Cloudflare 的免费隧道工具（单文件，不用安装）：

   打开 <https://github.com/cloudflare/cloudflared/releases/latest>
   下载 `cloudflared-windows-amd64.exe`，改名为 `cloudflared.exe`，放到 `C:\cloudflared\`

3. 运行：

   ```bat
   C:\cloudflared\cloudflared.exe tunnel --url http://localhost:3000
   ```

4. 窗口里会出现一行：

   ```
   https://xxxx-xxxx.trycloudflare.com
   ```

   这就是你的临时公网地址。打开 `https://xxxx.trycloudflare.com/api/health` 验证。

**限制（一定要知道）：**

- 你的电脑必须一直开着、后端窗口不能关
- 每次重启隧道，地址都会变
- 它只适合临时演示，不适合长期放着

> 这条路的优点：**不用注册账号、不用绑卡、不用买服务器、不用域名**。
> 适合「今天就要发给 HR 看一眼」的场景。

## 第 9 节：最常见的 8 个问题

| 问题 | 答案 |
|---|---|
| 我什么都没有，要买服务器吗？ | 不用。录屏用 GitHub 免费机器，后端用 Render 免费实例或本机隧道。 |
| 要买域名吗？ | 不用。Render 和 Pages 都送免费域名。 |
| 要装 Android Studio / Xcode 吗？ | 拿自动录屏不用。只有你想在本机跑模拟器时才需要 Android Studio；Xcode 只有 Mac 能装。 |
| 要会 Linux 吗？ | 不用。Render 是网页点选；Docker 命令只有三行，文档里可以直接复制。 |
| 令牌会不会泄露？ | 存在 `secrets/token.txt`，该目录被 git 忽略。别发人、别传网盘；怀疑泄露就去 GitHub 撤销。 |
| 自动录屏只有 45 秒，会被认为功能少吗？ | 它已经包含记一笔、保存、统计、切月份，是完整的功能演示。想更稳可以再补一段手机录的 60~90 秒。 |
| GitHub Actions 要钱吗？ | 公开仓库的 standard runner 免费。这个项目用的都是标准机器。 |
| Render 打不开 / 很慢怎么办？ | 国内访问海外服务不稳定是常态。换时间重试，或用第 6 节的隧道，或部署到国内免费试用主机。 |

---

## 第 10 节：不要做的事

- **不要**为了「双端原生」四个字去重写成 Kotlin + Swift 两套。时间不够，而且这个项目的价值是「真的能跑」。
- **不要**在录屏里露出真实姓名、手机号、真实账单。
- **不要**把 `secrets/token.txt`、`.env`、`dist/` 提交到 GitHub。
- **不要**买付费服务器再开始。先用免费的把流程跑通。
- **不要**在 Actions 红叉时反复点重跑。先打开日志看第一个红叉，把报错复制给 AI。
