# 01 · 环境搭建（Windows）

目标：让 `flutter doctor` 全部打勾。

**预计耗时：2～4 小时**（大半时间在下载）。装不完不要紧，分两次也行。

---

## 0. 你机器上已经有的

| 工具 | 状态 | 说明 |
|---|---|---|
| Git | ✅ 2.36.1 | 够用 |
| Node.js | ✅ 24.15.0 | 后端直接能用 |
| Java | ⚠️ 24.0.1 | **这里有个坑，见第 4 步** |
| Flutter | ❌ 没装 | 本步要装 |
| Android Studio | ❌ 大概率没装 | 本步要装 |

## 1. 设国内镜像（先做，能省几个小时）

Flutter 的 SDK 和公开包仓库都在国外，不设镜像可能下载到一半断掉。

**Win + R** 输入 `sysdm.cpl` → 高级 → 环境变量 → 在「用户变量」里新建两条：

| 变量名 | 值 |
|---|---|
| `FLUTTER_STORAGE_BASE_URL` | `https://storage.flutter-io.cn` |
| `PUB_HOSTED_URL` | `https://pub.flutter-io.cn` |

> 镜像地址是会变的。如果设完下载反而失败，把这两条删掉重试直连。
> 备选镜像：清华 `https://mirrors.tuna.tsinghua.edu.cn/dart-pub`

**设完必须重开终端才生效。**

---

## 2. 装 Flutter SDK

1. 打开 <https://docs.flutter.cn/get-started/install/windows>
2. 下载 **stable** 版的 zip（大概 1 GB）
3. 解压到 **`C:\src\flutter`**

三个「千万别」：

- ❌ 别解压到 `C:\Program Files\` —— 有权限限制，后面写文件会失败
- ❌ 路径里别有任何中文或空格
- ❌ 别解压到 `C:\Users\你的名字\Downloads\` 里就跑 —— 后面容易手滑删掉

正确结果应该长这样：`C:\src\flutter\bin\flutter.bat` 这个文件存在。

### 加 PATH

`sysdm.cpl` → 高级 → 环境变量 → 找到「用户变量」里的 `Path` → 编辑 → 新建 → 填：

```
C:\src\flutter\bin
```

**重开终端**，然后：

```bash
flutter --version
```

第一次跑会花几分钟（它在初始化 Dart SDK），正常。看到版本号就成了。

---

## 3. 装 Android Studio

1. 下载：<https://developer.android.com/studio>（约 1 GB）
2. 安装时一路默认，**记得勾上 Android Virtual Device**
3. 首次启动选「Standard」安装

装完后，在 Android Studio 里打开：
**More Actions → SDK Manager → SDK Tools**，勾上这三项：

- ☑ Android SDK Command-line Tools (latest)  ← **最容易漏，漏了就 `flutter doctor` 报错**
- ☑ Android SDK Platform-Tools
- ☑ Android SDK Build-Tools

点 Apply 等它下完。

### 接受许可

```bash
flutter doctor --android-licenses
```

一路按 `y` 回车。中途会要你确认好几次。

---

## 4. ⚠️ 你机器上的 Java 24 会出问题

Flutter 的 Android 构建走 Gradle，Gradle 对 JDK 版本有明确上限。**Java 24 太新，会报 `Unsupported class file major version`。**

不要卸载你的 Java 24（可能别的项目在用）。让 Flutter 改用 Android Studio 自带的 JDK：

```bash
flutter config --jdk-dir="C:\Program Files\Android\Android Studio\jbr"
```

> 路径不确定的话，在 Android Studio 里看：
> **Help → Show Log in Explorer** 附近，或直接到 `C:\Program Files\Android\Android Studio\` 下找 `jbr` 文件夹。
> 有些版本是 `C:\Program Files\Android\Android Studio\jre`。

验证：

```bash
flutter doctor -v
```

输出的 `Java binary at:` 一行，应该指向 Android Studio 的 `jbr`，**不应该**指向你系统的 Java 24。

## 5. 建一个模拟器

Android Studio 里：**Device Manager → Create Device**

- 机型选 **Pixel 7**（或任意 Pixel）
- 系统镜像选 **API 34** 或 **35**，注意看架构：
  - 你的电脑是 Intel/AMD 的 x86 芯片 → 选 **x86_64**
  - Apple 芯片的 Mac → 选 arm64（你不需要管这条）
- 名字随便，比如 `pixel7`

### 模拟器起不来 / 卡成幻灯片？

Win + R 输入 `optionalfeatures`，确认这几项是勾上的：

- ☑ Hyper-V
- ☑ Windows 虚拟机监控程序平台
- ☑ 虚拟机平台

勾完**要重启电脑**。

如果公司电脑锁了这些功能、或者模拟器还是卡得没法用——**直接用真机**，反而更流畅，而且录屏更好看：

1. 手机开发者选项打开、USB 调试打开
2. USB 连电脑，手机上点「允许调试」
3. `flutter devices` 能看到你的手机就行

## 6. 验收

```bash
flutter doctor
```

理想输出：

```
[✓] Flutter (Channel stable, ...)
[✓] Windows Version (...)
[✓] Android toolchain - develop for Android devices (...)
[✓] Chrome - develop for the web          ← 用不到，无所谓
[✓] Visual Studio - develop Windows apps  ← 用不到，✗ 也没关系
[✓] Android Studio (...)
[✓] Connected device (1 available)
[✓] Network resources
```

**只需要看到 Flutter、Android toolchain、Android Studio 三项是 ✓，就能继续了。**

`Visual Studio` 和 `Chrome` 报红**不用管** —— 那是给 Windows 桌面应用和网页版用的，我们这个项目不碰。

## 7. 常见报错

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `flutter : 无法将"flutter"项识别为...` | PATH 没生效 | 关掉**所有**终端窗口重开。还不行就检查 `C:\src\flutter\bin\flutter.bat` 在不在 |
| `cmdline-tools component is missing` | 第 3 步那个勾没勾 | 回 Android Studio 的 SDK Manager 勾上 |
| `Android license status unknown` | 没接受许可 | `flutter doctor --android-licenses`，一路 y |
| `Unsupported class file major version 68` | Java 24 冲突 | 回第 4 步 |
| `Unable to find bundled Java version` | Flutter 找不到 AS 的 JDK | 回第 4 步，或者手动指定 `jre` 目录 |
| 下载卡住 / 超时 | 镜像没设或镜像挂了 | 回第 1 步 |
| `Failed to connect to ...: Connection refused` | 模拟器没起来 | Android Studio 里手动启动模拟器，等它完全开机 |
